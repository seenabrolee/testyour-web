회식 자리 경품 추첨이나 팀 프로젝트 조 배정, 온라인 이벤트 당첨자를 뽑을 때 가장 중요한 것은 '누구에게나 완벽히 동등한 확률이 적용되는가'입니다. TESTYOUR의 랜덤 뽑기 도구는 별도 프로그램 설치나 회원가입 없이 웹 브라우저에서 바로 공정한 선별 작업을 수행할 수 있도록 설계되었습니다.

1. 왜 일반 랜덤 정렬 대신 '피셔-예이츠(Fisher-Yates) + 암호학적 난수'를 쓰나요?

간단하게 만들어진 일부 웹 뽑기 도구는 자바스크립트의 Array.sort(() => Math.random() - 0.5) 방식을 사용하곤 합니다. 하지만 이 방식은 브라우저 엔진의 정렬 알고리즘 특성상 특정 위치의 이름이 더 자주 뽑히거나 덜 뽑히는 통계적 편향이 발생할 수 있습니다.

본 추첨기는 브라우저 표준 Web Crypto API의 암호학적 난수 생성기(crypto.getRandomValues)와 기각 샘플링(Rejection Sampling) 기반 피셔-예이츠 셔플을 결합해, 입력된 모든 참가자가 정확히 동일한 확률(1/N)로 선택되도록 보장합니다.

  • 추가/패자부활 추첨: 1차로 5명을 뽑은 뒤, 이미 당첨된 사람을 빼고 남은 인원 중 추가 뽑기 버튼으로 결원 보충

3. 자주 묻는 질문 (FAQ)

Q. 입력한 이름이나 개인 명단이 서버에 저장되나요?
아니요. 참가자 명단 파싱부터 난수 생성, 결과 출력까지 모든 연산은 사용자의 브라우저 기기 안에서만 오프라인처럼 동작하며, 입력하신 이름은 외부 서버로 전송되거나 기록되지 않습니다.

Q. 엑셀이나 카톡에서 복사한 명단을 그대로 붙여넣어도 되나요?
네. 줄바꿈(엔터), 쉼표(,), 띄어쓰기를 자동으로 구분해 인식하며, 빈 줄이나 불필요한 여백을 깔끔하게 정리해 줍니다. 동명이인이 아니라면 '중복 이름 자동 제거' 옵션을 켜 두어 실수로 한 사람이 두 번 들어가는 것을 막을 수 있습니다.
